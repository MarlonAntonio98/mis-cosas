# Mis cosas

Todo lo que tienes con su foto, dónde está guardado, a quién se lo prestaste y sus garantías.

## Publicarla

1. Crea un repositorio público llamado `mis-cosas` y sube todos estos archivos a la raíz.
2. En **Settings → Pages** elige la rama `main` y la carpeta `/ (root)`.
3. Abre en Chrome `https://tu-usuario.github.io/mis-cosas/` e instálala.

## Actualizar la app

Si cambias algún archivo, abre `sw.js` y sube el número de `VERSION` (por ejemplo, de `cosas-v1` a `cosas-v2`).
